3 systèmes de formulaires

Angular propose désormais trois approches pour gérer les formulaires

Système Approche Package Statut
Template-driven Directives + [(ngModel)] @angular/forms Stable
Reactive Forms FormGroup / FormControl / RxJS @angular/forms Stable
Signal Forms form() / FormField / Signals @angular/forms/signals Experimental
Signal Forms ne sont pas une évolution des Reactive Forms — c'est une réécriture from scratch
Conçu pour l'ère post-Zone.js et signals-first
API experimental — peut changer à tout moment, y compris dans un patch
La v22 (mai 2026) est un candidat pour la stabilisation, sans garantie
